Why did n8n-as-code lose 4 nodes on schema validity?
The n8n canvas UI hides inactive conditional parameters without displaying red error icons. However, the server's strict RPC validator flagged: Simple Memory (sessionKey without sessionIdType="customKey"), Google Calendar Tool (missing calendar.__rl: true), Daily Briefing Orchestrator (text without promptType="define"), and OpenAI Chat Model (builtInTools without responsesApiEnabled=true). These discrepancies provide clear feedback to tighten n8nac's local TypeScript schema validator.

Methodology & Impartiality Protocols

Standards for community reproduction

To prevent instance contamination and benchmark gaming on shared instances, workers operate under strict hermetic sandboxes:

Standard Implementation Rule
Universal Confinement INTERDICTION FORMELLE : Vous ne devez JAMAIS lister, rechercher ou inspecter les workflows existants sur l'instance n8n.
Opaque Naming Mandatory generic naming: workflow-<timestamp> (zero leak of task keywords like email or calendar).
Universal Minimax Score(X) = 100 × min(A, B) / X applied across latency and tokens. Prevents arbitrary floor-effect collapse.
Zero Subjectivity 100% deterministic code evaluation via validator.mjs and compiler.mjs.
